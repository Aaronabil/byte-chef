# Byte Chef

Chain encode and decode steps in the browser. Everything runs client-side; nothing is uploaded.

**Live (GitHub Pages):** https://aaronabil.github.io/byte-chef/

## Features
- To Base64 / From Base64 (with URL-safe option)
- To Binary / From Binary (separator options)
- To ASCII codes / From ASCII codes (Decimal / Hex / Octal, separator options)
- Chain multiple steps, reorder with up/down, per-step error highlighting

## Run locally
Just open `index.html` in a browser. No build, no server, no dependencies.

## Deploy
This repo is hosted with GitHub Pages: Settings → Pages → Deploy from branch `main` / root.
